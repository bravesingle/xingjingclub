> 状态：代码已实现并通过 `nest build`。当前 `.env` 仍为 `PAY_MOCK=true`（不产生真实扣款），
> 按下面步骤翻转后才走真实微信支付。

## 二、上线前必须翻转的开关（缺一不可）

1. **后端 `server/.env`**
   - `WECHAT_MOCK=false`，并填入真实 `WECHAT_SECRET`（登录拿真实 openid，JSAPI 支付必须有真实 openid）
   - `PAY_MOCK=false`（走真实下单）
   - 确认 `WXPAY_*` 已填（见下方）
2. **小程序 `config/index.js`**
   - `env: 'dev'` → `'prod'`
   - `useMockPay: true` → `false`
   - `anonLogin: true` → `false`（登录走 wx.login code）
   - `baseUrl.prod` / `wsUrl.prod` 需为**已备案 HTTPS 域名**
3. **微信公众平台**：把 `https://<你的域名>/api/pay/wechat/notify` 加入小程序后台
   「开发管理 → 开发设置 → 服务器域名 → request/socket 合法域名」。
   （`wx.requestPayment` 本身不需要域名白名单，但调用后端 prepay 需要 request 域名。）

## 三、`server/.env` 中 WXPAY_* 示例

```env
WXPAY_MCHID=1117078862
WXPAY_SERIAL_NO=5D1FE283ABC3601C858484BBE5FB0BCBECE8D0F2
WXPAY_APIV3_KEY=<你在商户平台设置的APIv3密钥>
WXPAY_PRIVATE_KEY=certs/apiclient_key.pem
WXPAY_PUBLIC_KEY=certs/wechatpay_pub.pem
WXPAY_PUB_KEY_ID=            # 平台公钥ID，可留空（跳过序列强校验）；公钥轮换时需更新 wechatpay_pub.pem
WXPAY_NOTIFY_URL=https://api.xingjingclub.cn/api/pay/wechat/notify
```

证书文件（`apiclient_key.pem`、`apiclient_cert.pem`、`wechatpay_pub.pem`）需放在 `server/certs/`
（该目录已被 `.gitignore` 排除，勿提交）。

> 金额单位：微信支付与订单均以「分」为单位，代码已对齐，无需换算。

## 四、完整验证步骤（真实环境）

1. `cd server && npm install && npm run build`
2. 确认 `.env` 按第二节翻转、`certs/` 有证书
3. 启动：`npm run start:dev`（或 pm2 `node dist/main.js`）
4. 小程序开发者工具（正式 AppID，真机预览）下单 → 微信收银台 → 支付成功
5. 支付后约 1~2 秒，后端收到回调日志 `✅ 微信支付成功: order=...`，订单自动变已支付
   - 若没收到：检查 `WXPAY_NOTIFY_URL` 公网可达、HTTPS 证书有效、域名已加白名单
6. 兜底：小程序端可调 `queryPayResult` 轮询订单状态

## 五、尚未接入（后续需同样处理）

- **余额充值 / 押金**：`fund.service.ts` 的 `recharge` / `payDeposit` 在 `PAY_MOCK=false`
  时会主动抛错（防免费入账）。如需真实充值/押金，需按同样方式为它们走 JSAPI 下单
  （它们当前没有独立预下单接口，需要新增）。
- **退款**：微信支付退款（V3 `refund` 接口 + 商户证书）尚未实现，当前退款为站内状态流转；
  真实退款需接入 `/v3/refund/domestic/refunds` 并处理回调，涉及商户证书与 APIv3 密钥。
- **对私打款给打手**：按业务规划（冻结 7 天后线下/其他通道结算），不走微信，无需本模块处理。

## 六、风险提示

- **特约商户自研**：若你的商户号在微信支付侧被判定必须走「服务商模式」（partner API），
  本代码为「直连商户模式」（`/v3/pay/transactions/jsapi`）。当前已按你确认的直连实现；
  若实际下单返回 `商户号类型不正确` 类错误，需改为 partner 接口并换成服务商证书。
- 平台抽成 + 打手结算模式仍存在被微信风控关注的可能，正式跑量前建议小额试跑并关注
  结算/投诉/风控提示。
